# I18N

## Language state must use useSyncExternalStore (SSR-safe, lint-clean)
The LanguageProvider reads the stored locale from localStorage but must render 'id' on the server to avoid hydration mismatch. Do not replace this with a lazy useState initializer (causes hydration mismatch) or a setState call inside an effect (fails the react-hooks/set-state-in-effect lint rule that's enabled with React Compiler). Keep useSyncExternalStore with getServerSnapshot() === 'id'.
